Features

Built for clear demos.

A small native menu bar app that stays out of your way and out of the Dock.

Keycaps and shortcut badges

Each key appears as a rounded keycap, and combinations like Command-Shift-4 are grouped into one compact badge. Typed text merges into a single chip that grows as you type.

All Keys or Shortcuts Only

Show everything, or only combos that include Command, Control or Option. Adjust fade delay, keycap size, text size, opacity and a light, dark or accent color scheme.

Mouse click badges

Optionally show left, right and middle clicks near the pointer so viewers can see what you pressed and where.

Pauses for password fields

While macOS secure input is active, the overlay is cleared and paused. Keystrokes are only drawn on screen, never written to disk or sent over the network.

Place it where you need it

Choose bottom center, bottom left, bottom right, top center or follow the active screen, and pick which display to use. The overlay is click-through and joins all Spaces.

Native and lightweight

Written in SwiftUI and AppKit with no third-party code. It follows your keyboard layout, supports launch at login and re-enables its event tap if the system disables it.

Install

Up and running in a minute.

KeyCapOverlay is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download KeyCapOverlay-macOS.zip and unzip it.
  2. Move KeyCapOverlay.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/KeyCapOverlay.app
  4. When prompted, grant Accessibility access to KeyCapOverlay in System Settings Privacy Security Accessibility so it can see key presses and clicks.

FAQ

Questions, answered.

Is KeyCapOverlay really free and open source?

Yes. It is released under the MIT license and the full source is on GitHub, with no account, ads or paid tier. If it is useful to you, there is an optional Support button that links to Ko-fi.

What permissions does it need?

Only Accessibility, so a listen-only event tap can see key presses and mouse clicks. It does not request Screen Recording or Microphone access, because it does not capture the screen or audio.

Where is my data stored?

Keystrokes stay in memory, are drawn on screen and are never written to disk or sent anywhere. The only thing saved is your settings, such as position, mode and hotkey, which macOS stores in the app's preferences.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to get past Gatekeeper, or build it yourself from source.

Was this written by AI?

Yes. KeyCapOverlay was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
